
# FORMA Restaurant & Bistro

## Project Overview

FORMA Restaurant & Bistro is an educational website project for a fictional modern restaurant located in Bălți, Republic of Moldova.

The website presents the restaurant concept, sample menu, photo gallery, contact information, and a demonstration table reservation form.

## Live Website

[Open the FORMA Restaurant website](https://lenconcoira2007-spec.github.io/forma-restaurant/)

## Main Features

- Modern restaurant landing page
- Restaurant introduction and concept
- Menu with sample dishes and illustrative prices
- Photo gallery
- Demonstration reservation form with validation and feedback
- Russian, Romanian, and English language options
- Responsive layout for desktop and mobile devices
- Contact information and opening hours

## Technologies

- **HTML5** — website structure
- **CSS3** — styling and responsive layout
- **JavaScript** — interactive elements, language switching, and form behavior
- **GitHub** — source code hosting and project documentation
- **GitHub Pages** — website publishing

## Project Limitations

This is a student project created for educational purposes. The restaurant is fictional. Menu prices and contact details are illustrative. The reservation form demonstrates the user interface and does not create real reservations, store booking information in a database, or accept payments.
