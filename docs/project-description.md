# Project Description — FORMA Restaurant

## 1. Project Overview

FORMA is a minimalistic website concept for a modern restaurant. The website will present the restaurant, display its menu, show photos of the interior and dishes, and provide contact information.

## Client Information

The client is a fictional owner of the FORMA Restaurant & Bistro, created for educational purposes.

The client needs a website to present the restaurant online, introduce visitors to the menu and atmosphere, display opening hours and contact information, and allow visitors to submit a table reservation request.

The website is a student project. It does not process real reservations, store booking data in a database, or accept online payments.

## 2. Project Objectives

- Create a simple and attractive restaurant website.
- Make the menu easy to browse.
- Allow visitors to submit a table reservation request.
- Display opening hours and contact details.
- Ensure the website is convenient to use on computers and mobile devices.

## 3. Target Audience

The website is intended for people who want to explore the restaurant menu, learn about the restaurant, or request a table reservation.

## 4. Planned Pages and Sections

- Home
- About the Restaurant
- Menu
- Gallery
- Reservations
- Contacts

## 5. Planned Technologies

- HTML — page structure
- CSS — visual design and responsive layout
- JavaScript — interactive elements and reservation form validation

## 6. Expected Result

A working website prototype with a consistent visual style, clear navigation, restaurant information, menu presentation, gallery, and a reservation request form.

## 7. Project Team

The project is planned for a team of three students. Team members and their responsibilities will be added after the roles are agreed upon.
